Between September and November 2026 I built 52 projects; 43 are live on the web and fourteen update themselves. I measure my AI experiments with hidden tests and confidence intervals, and I write up the ones that didn't work, with their results. Some of my apps have real users: my family, my uncle, local shops, and the players of a party game.

Selected projects

Mevzuat Haritası (Legislation Map)

Python · data pipeline · OCR

Turkey's Official Gazette 2000–2026: 99,697 regulations from the index of 10,608 issues; a site showing which law changed how often. birtohum.github.io/mevzuat-haritasi

Meclis'in Dili (The Language of Parliament)

Python · text processing · JS

Parliamentary records 1996–2026: 3,731 sessions, 69M words; an Ngram-style site for word frequency by year and an open dataset of 992,319 speeches (Hugging Face). birtohum.github.io/meclisin-dili

Usta

Python · LLM agent · evaluation

A Turkish coding agent where a second model writes tests without seeing the code. 114 tasks × 3 repeats, 1,026 runs with hidden tests: independent verification gave no gain (60% → 58%), and the reason was measured. Meta AI Developer Hackathon entry. github.com/birtohum/usta

Tohum

PyTorch · LoRA · H100

A 4.8M-parameter character-level Turkish language model trained from scratch (RTX 3060, 21 min); fine-tuned Qwen3-8B with LoRA on Turkish instructions, beating the official model 10–2 on a 30-question test. 156,334-example dataset open on Hugging Face.

Turkish AI report card

Wikidata · bootstrap · evaluation

10 models on 1,209 auto-generated Turkey questions, with confidence intervals: Meta API models 98%, local open models ≤49%. Live site

Sepet Enflasyonu · Kaç Sigara? · İETT Dakiklik

GitHub Actions · scheduled jobs

Three sites that collect their own data every day: an 83-item grocery basket index compared with CPI; province-level PM2.5 from the ministry's 210 stations; Istanbul bus punctuality from İETT's live vehicle positions.

Ten sites on open data

Python · satellite data · JS

Street names: 3.9% of person-named streets honour women (OSM + LLM, hand-checked); province-level earthquakes (EMSC/USGS); VIIRS night lights for 973 districts; aircraft over Istanbul (OpenSky); water surface of 10 reservoirs (Sentinel-2); Wikipedia spikes; sea temperature (NOAA, 1981+); wildfires (NASA FIRMS, 2001+); Turkish TV series in 87 languages; satellite passes (SGP4).

Seslendir.io

Next.js · TypeScript · VPS

A multiplayer "blind dubbing" party game, live with real players on its own server (AWS EC2, pm2, Caddy); 939 dubs and 10,830 recorded lines; 23 free tools (subtitles, vocal separation, image generation). seslendir.site

Bizim Masa

React Native · Expo · Firebase

A password-free, large-text family games room for my parents: 13+ games, turn-based or live; rules live in tested engine files and moves are validated on the server.
